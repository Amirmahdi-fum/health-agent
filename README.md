# ❤️ Health Agent — Your AI-Powered Health OS

Body-health tracking app with an AI coach: log calories, water, cardio and study time, watch weight / BMI trends on charts, and chat with the coach about workout plans, diet, and health tracking.

## ✨ Features

- 📊 Dashboard — calories vs TDEE, water, cardio, weight trend, BMI / BMR
- 🤖 AI coach chat (workout plans, diet, health tracking)
- 📝 Daily logs · 📈 smart progress analytics & charts
- 👥 Friends · 👤 public profiles · ⚙️ settings
- 🔐 Auth + Supabase backend

## 🛠️ Stack

TanStack Start · React · TypeScript · Tailwind CSS · Supabase · AI SDK

## 🚀 Run

```bash
bun install
bun run dev
```

Needs Supabase credentials in `.env` (see `.env` for the required keys).
